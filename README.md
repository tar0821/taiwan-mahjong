# 台麻十六張

台灣十六張麻將網頁版。開房後把連結傳給朋友，四人或兩人線上一起打，人不夠可以讓電腦補位，也可以自己跟電腦打。

**開始玩：** https://tar0821.github.io/taiwan-mahjong/

## 怎麼跟朋友打
1. 打開網站，輸入暱稱，選四人或兩人麻將，按「開房邀朋友」。
2. 按「傳連結給朋友」，用 LINE 傳出去。朋友點開連結就會直接進房。
3. 座位坐滿（或按「電腦補位」）就按「開始打牌」。

房主的瀏覽器負責跑牌局，房主要一直開著頁面、手機不要鎖螢幕。

## 規則
- 四人：144 張（含花），留尾 16 張，莊家與連莊算台，台數依一般台麻。
- 兩人：只用萬子＋字牌（64 張，可選有花／無花），不留尾，莊家不算台，台數依兩人台麻規則。
- 開局：房主擲骰定東，東家擲骰開門；莊家沒胡就換下家當莊。
- 有聽牌鍵：聽牌後自動摸打、自動胡（不加台）。

## 技術
單一檔案 `index.html`，沒有後端。線上連線用 [PeerJS](https://peerjs.com/)（WebRTC 點對點），房主的瀏覽器就是伺服器。
